The Safety Stack is a public inventory of the techniques used to make frontier AI models safe. Currently, frontier labs rely on a defence-in-depth approach that compiles many weak safety techniques together so that the failures of one layer (hopefully) get caught by the next. We don’t know how good a strategy this is, as the actual stack deployed in any given lab is not public.

So we tried to find out. We built the inventory from published papers and from open-source evidence of what labs are probably using. Alongside it we are building a model that breaks threats into concrete slices, so that you can see which threats may have no cover or depend on only a single safeguard. All data and code are public and are updated every week. Read more →
